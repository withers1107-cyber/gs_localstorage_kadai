しゃべる石膏像の部屋

## 2.制作アプリの説明
個性豊かな石膏像たちが、日々の作業や勉強、気分の落ち込みに寄り添い、励ましてくれるWebアプリケーションです。  
私が通っている、絵画教室の先生が、いつも石膏像に楽しそうに石膏像について説明してくれて、話しかけているのを見て楽しそうだなと思い、
会話できたらいいなと思って作りました。
また、通っているジムのインストラクターさんが、とてもポジティブで優しいギャルなのでそんな人柄を再現したいと思いました。

## 主な機能
* **個性豊かな7体の石膏像キャラクター**
  * 会話を重ねるごとに新しい石膏像がアンロック（解放）されます。
  * 「石膏像図鑑」モーダルから、解放済みのキャラクターのプロフィール閲覧や切り替えが可能です。
* **3つの会話モード切り替え**
  * **肯定モード**：存在や努力を全力で褒め称えます。
  * **共感モード**：疲れや弱音に静かに寄り添い、受け止めます。
  * **応援モード**：背中を強く押し、気合を入れて鼓舞します。
* **RPG風テキスト表示＆音声読み上げ**
  * 発言のあとに少し「間」を置いてから、RPGのメッセージウィンドウのように1文字ずつテキストが表示されます（吹き出しクリックでスキップ可能）。
* **ワンタップ会話＆漫画風チャット履歴**
  * 「疲れた〜」「褒めて！」「やる気出ない…」などのクイックボタンで手軽に会話できます。
  * 会話履歴は漫画の吹き出し風に左右へ表示され、ブラウザの LocalStorage に自動保存されます。

## 3.工夫した点・こだわった点
多分、本当にいた方なので、どんな人なのか調べてキャラクター設定することにこだわりました。
会話しているみたいに一文字ずつ表示が出るように工夫しました。
気分によってモードを変更できるのと、会話を重ねると会話できるキャラクターが増えるようにしました。
